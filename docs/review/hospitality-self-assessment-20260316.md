### 2.3 取消政策清晰度

#### 现状问题
**当前实现**: 统一显示"24h免费取消"

**问题**: 
1. 实际政策可能因酒店而异
2. 未明确说明取消时间计算方式
3. 未说明退款到账时间

**行业最佳实践**:
```typescript
type CancellationPolicy = 
  | 'flexible'      // 入住前24h免费取消
  | 'moderate'      // 入住前5天免费取消  
  | 'strict'        // 入住前7天免费取消，之后50%
  | 'non_refundable'; // 不可退款（有折扣）

// 展示标准
<CancellationBadge policy="flexible">
  <Icon>✓</Icon>
  <Label>Flexible</Label>
  <Description>Full refund before Mar 20, 12:00 PM</Description>
</CancellationBadge>
```

**优先级**: P0 - 必须在上线前完成

### 3.2 价格税费透明度

#### 行业合规要求
根据OTA行业标准，所有价格展示必须:
1. 明确区分"每晚价格"和"总价"
2. 展示所有费用明细（清洁费、服务费、税费）
3. 使用用户选择的货币展示

#### 现状问题
```typescript
// 当前 - 不符合标准
<div className="price">${hotel.pricePerNight}/night</div>
// 问题：仅展示每晚价格，用户到结账才发现总价

// 应改为 - 符合标准
<div className="price-section">
  <div className="per-night">${basePrice}/night</div>
  <div className="total">${totalPrice} total</div>
  <div className="breakdown">includes taxes & fees</div>
</div>
```

**优先级**: P0 - 必须在上线前完成
