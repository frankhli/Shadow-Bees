## 📐 间距速查

```
4px  → xs  → 图标间隙、紧凑间距
8px  → sm  → 相关元素间距
16px → base → 组件内边距
24px → lg  → 卡片内边距
32px → xl  → 区块间距
48px → 2xl → 大模块间距
64px → 3xl → 页面区块间距
```

## 🎯 设计原则速记

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. 颜色 ≤ 5 种              → 克制用色                     │
│  2. 字体 ≤ 3 种              → 清晰层级                     │
│  3. 圆角: 8/12/16px          → 一致性                       │
│  4. 阴影: xs/sm/md/lg        → 层次分明                     │
│  5. 留白是设计元素            → 呼吸感                      │
│  6. 参考 Linear/Vercel        → 高级感                      │
│  7. 参考 Booking             → 专业感                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
