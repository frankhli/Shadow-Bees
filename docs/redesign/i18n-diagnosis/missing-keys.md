## 🔧 快速修复指南

### 方法1: 直接编辑JSON文件

1. 打开对应的语言文件（如 `de.json`）
2. 找到对应的父级键
3. 添加缺失的子键

### 方法2: 使用脚本合并

```bash
# 示例：合并缺失的键到de.json
node scripts/merge-translations.js de
```

### 方法3: 使用jq命令行工具

```bash
# 添加common.months到de.json
jq '.common.months = {
  "jan": "Januar",
  "feb": "Februar",
  ...
}' de.json > de.json.tmp && mv de.json.tmp de.json
```
