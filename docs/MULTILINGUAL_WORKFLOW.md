# 多语言工作流设计

## 核心原则

**B端中文操作 → AI生成/翻译 → 五语同步输出 → C端多语言服务**

---

## 语言支持

| 语言 | 代码 | 使用场景 |
|------|------|---------|
| 中文 | zh | B端操作界面、人工回复 |
| 英语 | en | 默认外语 |
| 西班牙语 | es | 拉美游客 |
| 法语 | fr | 欧洲游客 |
| 德语 | de | 欧洲游客 |
| 日语 | ja | 日本游客 |

## 一、AI内容生成工作流

### 场景1：酒店OTA描述

```
B端操作：
1. 填写中文描述 → "胡同里的精品四合院酒店，步行可达故宫"
2. AI生成 → 中文版确认
3. 一键翻译 → 英/西/法/德/日五语
4. 预览五语效果
5. 发布到各平台

C端效果：
- 外国游客看到的英文："A boutique siheyuan hotel in the hutong..."
```

### 场景2：小红书种草文案

```
B端操作：
1. 输入中文关键词 → "胡同、四合院、老北京"
2. AI生成 → 中文文案
3. 确认后同步生成 → 英/西/法/德/日版本
4. 用于Instagram/TikTok等多平台
```

### 场景3：导游个人介绍

```
B端操作：
1. 编辑中文介绍 → "10年北京胡同讲解经验"
2. AI翻译 → 五语版本
3. 外国游客看到的：对应语言版本
```

## 二、AI智能客服工作流

### 实时对话流程

```
外国游客（英语）：
"Do you have elevator in the hotel?"

↓ AI实时翻译 ↓

B端显示（中文）：
"客人问：酒店有电梯吗？ [原文: Do you have elevator...]"

↓ 酒店回复（中文）↓
"我们是传统四合院，没有电梯，但提供行李搬运服务"

↓ AI实时翻译 ↓

外国游客看到（英语）：
"As a traditional siheyuan, we don't have an elevator, but we offer complimentary luggage assistance."
```

### 人工接管场景

```
当AI置信度 < 0.7 或 客人要求人工时：

B端工作台显示：
- 客人原文：英文
- AI翻译：中文
- 建议回复：中文（可编辑）

酒店编辑中文回复 → AI翻译 → 客人看到英文
```

### 语言标识

B端界面显示：
```
💬 新消息
来自：John Smith 🇺🇸 [EN]
内容："Do you have..."
AI翻译："酒店有电梯吗？"
```

## 五、B端导航说明

### 酒店端

- **AI内容生成** → 中文编辑 + 五语管理
- **AI智能客服** → 实时翻译对话
- **AI动态定价** → 多币种支持
- **多语言管理** → 五语内容库、翻译审核

### 导游端

- **AI个人品牌** → 中文介绍 + 五语版本
- **AI客户沟通** → 实时翻译
- **多语言服务** → 语言能力设置

### 体验店端

- **AI活动营销** → 中文活动 + 五语页面
- **AI活动咨询** → 实时翻译客服
- **多语言活动** → 五语内容库

### 管理端

- **多语言内容监管** → 五语内容审核、翻译质量检测
- **AI监管中心** → 实时翻译监控

---

## 六、注意事项

1. **文化适配**：AI翻译后需人工审核文化敏感内容
2. **术语统一**：建立术语库确保专业词汇一致性
3. **Fallback**：翻译失败时显示英文作为兜底
4. **人工审核**：关键内容（价格、政策）需人工确认
