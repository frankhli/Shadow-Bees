# Tiaohai Global - 功能规格说明书

## 概述

本文档详细描述各B端后台的功能规格，按优先级P0（必须）、P1（重要）、P2（优化）分级。

---

## 一、酒店端功能规格

### 1.1 经营概览 (/hotel)
**优先级：P0**

**功能列表：**
- [ ] 今日关键指标卡片
  - 今日入住数/订单数
  - 今日收入（人民币）
  - 待处理咨询数
  - 当前在住外宾国籍分布
- [ ] 房态概览（今日/明日/后日）
  - OTA池剩余 / Direct池剩余
  - 已售 / 总库存
- [ ] 最近订单列表（显示客人国籍标签 🇺🇸🇪🇸🇫🇷🇩🇪）
- [ ] AI待处理事项
  - 低置信度对话提醒
  - 价格异常提醒
- [ ] 快捷操作按钮
  - 修改今日房价
  - 查看AI客服
  - 发布内容

**数据来源：**
- 订单数据、库存数据、AI对话数据

---

### 1.2 房态日历 (/hotel/calendar)
**优先级：P0**

**功能列表：**
- [ ] 月视图日历
  - 每天显示：OTA池/Direct池/总库存
  - 颜色标记：紧张（<3间）/ 充足
  - 点击日期查看详情
- [ ] 双池库存管理
  - 拖动调整OTA池/Direct池分配
  - 批量设置（如：未来30天OTA池=5间）
- [ ] 价格日历
  - 每天显示：基础价 / AI建议价 / 实际售价
  - 点击修改单日价格
- [ ] 事件标记
  - 自动显示周边赛事/展会
  - 手动添加事件
- [ ] 批量操作
  - 批量修改库存
  - 批量修改价格

### 1.3 市场情报 (/hotel/market)
**优先级：P1**

#### 1.3.1 事件日历 (/hotel/market/events)

- [ ] 本城事件列表

- [ ] 价格监控

  - 价格趋势图（7天/30天）
- [ ] AI建议

#### 1.3.3 需求预测 (/hotel/market/forecast)
**功能列表：**
- [ ] 未来30天需求预测
