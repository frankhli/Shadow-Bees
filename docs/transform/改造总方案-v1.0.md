## 1. P0 关键改造（Week 1-2）

### 1.1 信任体系（酒店行业专家）

**问题**: 外宾担心酒店不接待、取消政策不透明

| 改造项 | 当前状态 | 改造方案 | 预期收益 |
|--------|----------|----------|----------|
| 外宾接待资质标识 | 仅有englishSpeaking | 添加官方认证badge + 资质说明页 | 信任度+30% |
| 护照/签证前置提示 | 结账页才收集 | 详情页明确提示"需携带护照" | 降低预订放弃率 |
| 取消政策透明化 | 统一24h免费取消 | 显示酒店实际政策 + 对比表 | 转化率+15% |
| 紧急联系方式 | 无 | 24小时英语热线 + WhatsApp | 安全感+25% |

**技术实现**:
```typescript
// 新增字段
interface Hotel {

  },

    phone: string,

  }
```

### 2.2 视觉系统统一（UI设计师）

**当前问题**: 两套并行视觉语言
- CSS定义：深色霓虹风格（#00F0FF）
- 实际页面：明亮Airbnb风格（#F43F5E）

**决策**: 采用**明亮Airbnb风格**
- 原因：更适合旅游预订场景，国际化认知度高

**新设计系统**:
```css
/* colors.css */
--primary: 346 100% 58%;        /* 玫瑰粉 #F43F5E - 热情活力 */
--primary-light: 346 100% 96%;  /* 浅粉背景 */
--background: 0 0% 100%;        /* 纯白 */
--text-primary: 222 47% 11%;    /* 深灰 */
--text-secondary: 215 16% 47%;  /* 中灰 */
--border: 214 32% 91%;          /* 浅灰边框 */

/* 间距体系 */
--space-xs: 4px;
--space-sm: 8px;
--space-md: 16px;
--space-lg: 24px;
--space-xl: 32px;
--space-2xl: 48px;
--space-3xl: 64px;
```
