## 1. 项目概述

### 1.1 背景
跳海Global是面向入境游客的酒店预订平台，聚焦跳海酒馆所在的中国五大城市（北京、上海、深圳、成都、广州），为国际游客提供便捷的住宿预订服务。

### 1.2 目标
- 重构C端网站（游客端），用于演示
- 使用免费资源，不额外产生服务器成本
- 支持5种语言：英语、西班牙语、法语、德语、日语（无中文）

### 1.3 约束条件
| 约束项 | 说明 |
|--------|------|
| 成本 | 零成本，使用免费资源 |
| 部署 | 不上服务器，使用静态托管 |
| 时间 | 优先MVP，快速验证 |

---

## 2. 用户画像

### 2.1 主要用户
**国际游客（入境游）**
- 年龄段：25-45岁
- 特征：自助游为主，使用英语或母语
- 需求：便捷预订、多语言支持、本地体验

### 2.2 用户旅程
```
发现 → 搜索 → 浏览 → 详情 → 预订 → 确认
```

## 3. 功能需求

### 3.1 P0 - 核心功能（必须实现）

#### P0-1 多语言首页
- **需求描述**: 网站首页支持5种语言切换
- **用户故事**: 作为国际游客，我希望用母语浏览网站，以便快速了解服务内容
- **验收标准**:
  - [ ] 首页完整翻译（英/西/法/德/日）
  - [ ] 语言切换器可见且可用
  - [ ] 切换后内容正确显示
  - [ ] URL支持语言参数（如 `?lang=en`）
- **技术方案**: i18n静态生成，JSON翻译文件
- **负责人**: Frontend Dev
- **预计工时**: 2天

#### P0-2 城市选择器
- **需求描述**: 支持5个城市的选择和展示
- **用户故事**: 作为游客，我希望按城市筛选酒店，以便找到目标城市的住宿
- **验收标准**:
  - [ ] 显示5个城市：北京、上海、深圳、成都、广州
  - [ ] 城市名称本地化为5种语言
  - [ ] 城市选择器在首页突出显示
  - [ ] 选择城市后跳转对应列表页
- **技术方案**: 静态JSON数据 + 路由参数
- **负责人**: Frontend Dev
- **预计工时**: 1天

#### P0-3 酒店列表页
- **需求描述**: 展示城市下的酒店列表
- **用户故事**: 作为游客，我希望看到某城市的所有可选酒店，以便比较选择
- **验收标准**:
  - [ ] 显示酒店卡片（图片、名称、价格、评分）
  - [ ] 支持价格排序
  - [ ] 空状态处理（无酒店时提示）
  - [ ] 响应式布局（移动端适配）
- **技术方案**: 静态JSON模拟数据
- **负责人**: Frontend Dev
- **预计工时**: 2天

#### P0-4 酒店详情页
- **需求描述**: 展示单个酒店的详细信息
- **用户故事**: 作为游客，我希望查看酒店详情，以便决定是否预订
- **验收标准**:
  - [ ] 图片画廊展示
  - [ ] 酒店名称、描述、设施列表
  - [ ] 价格信息
  - [ ] "立即预订"按钮（演示用，跳转外部）
  - [ ] 返回列表功能
- **技术方案**: 静态HTML模板
- **负责人**: Frontend Dev
- **预计工时**: 2天

#### P0-5 静态部署
- **需求描述**: 网站可部署到免费静态托管
- **用户故事**: 作为项目团队，我们需要一个可访问的演示地址
- **验收标准**:
  - [ ] 支持GitHub Pages / Vercel / Netlify 任一免费平台
  - [ ] 部署流程文档化
  - [ ] 自定义域名可选（使用免费子域名）
  - [ ] 构建产物优化（压缩、缓存）
- **技术方案**: GitHub Actions自动部署
- **负责人**: DevOps / Frontend Dev
- **预计工时**: 1天

## 4. 技术方案

### 4.1 技术栈推荐
| 层级 | 技术 | 说明 |
|------|------|------|
| 框架 | Next.js / Astro / VuePress | 静态生成，i18n支持 |
| 样式 | Tailwind CSS | 快速开发，响应式 |
| 部署 | GitHub Pages / Vercel | 免费托管 |
| 数据 | 静态JSON | 零后端成本 |

### 4.2 项目结构
```
tiaohai-global/
├── docs/                    # 文档
│   └── transform/
│       └── iteration1/
│           └── PRD_v1.md   # 本文件
├── src/
│   ├── i18n/               # 翻译文件
│   │   ├── en.json
│   │   ├── es.json
│   │   ├── fr.json
│   │   ├── de.json
│   │   └── ja.json
│   ├── data/               # 酒店数据
│   │   └── hotels.json
│   ├── components/         # 组件
│   ├── pages/              # 页面
│   └── styles/             # 样式
├── public/                 # 静态资源
└── .github/workflows/      # CI/CD
```

## 5. 设计规范

### 5.1 视觉风格
- **主色调**: 深海蓝 #1E3A5F（呼应"跳海"品牌）
- **强调色**: 珊瑚橙 #FF6B6B
- **背景色**: 白色 #FFFFFF / 浅灰 #F5F5F5
- **文字色**: 深灰 #333333 / 中灰 #666666

### 5.2 字体
- **英文**: Inter / Roboto
- **中文**: 系统默认（如需要）
- **日文**: Noto Sans JP

### 5.3 组件规范
- 按钮：圆角8px，主按钮纯色，次按钮描边
- 卡片：圆角12px，阴影0 2px 8px rgba(0,0,0,0.1)
- 间距：8px基准单位
